## Recommendation

1. **Shadow Sandbox** (set-1, total 16) — the Coding track's scariest demo (an agent
   writing code in front of judges) becomes the safe one: the agent works in a Token
   Factory shadow clone and only a verified diff, with its test report, is proposed, so
   the live demo cannot embarrass itself and "effective use of Nebius + NVIDIA" is
   visible in every step. Kill-risk: a coding-agent entry is a crowded genre; the shadow
   mechanism must be the star, not a footnote, or it blends into the field.
2. **Edge-Cloud Relay** (set-1, total 15) — the only candidate that uses two named
   NVIDIA model families (GROOT/Cosmos on a Jetson edge, Nemotron on Nebius cloud) in
   one coherent loop, and the mandatory 1-minute hardware clip is the rarest, most
   memorable demo moment in a remote hackathon. Kill-risk: it requires physical
   hardware in hand before the deadline — no Jetson or dev board, the candidate dies.
3. **The Overnighter** (set-2, total 15) — the Personal AI track's "always-on" and
   "persistent memory" requirements are proven instead of claimed: the demo opens with
   the morning report of Nebius Serverless work done overnight, which no competing demo
   can match with a live session. Kill-risk: the overnight run is necessarily
   pre-recorded, so the log trail must be inspectable in the video or the "was it really
   running?" question wins.

Method note: no first-principles (set-3), cross-domain (set-4), or inversion (set-5)
candidate reached the top 3. The first-principles candidates are minimal by
construction and thin on impact; the cross-domain framings (expediter gate, container
contract, checklist) are strong but need a host product to be demoable; the inversion
candidates are submission discipline — "Name the Audience, Number the Pain" (set-5) in
particular should be folded into whichever top-3 product is chosen, and it is listed in
the table as a pitch technique, not a product.
