Core contradiction: "improving effective use of the Nebius + NVIDIA infrastructure (the
top judging criterion) worsens the team's owned differentiation — the moat becomes the
infrastructure's, and the submission reads as a wrapper."

1. **Ownership Ledger** — a Personal AI assistant whose headline feature is that
   "own the whole thing" is a user action: one command exports every memory, skill, and
   tool binding to a second Nebius workspace, and the demo is the live migration.
   - Principle 22 (blessing in disguise) over the infrastructure-leverage vs ownership
     contradiction — the mandatory constraint becomes the product.
   - Judge leap: "open infrastructure" stops being a compliance checkbox and becomes the
     feature a tired judge can watch happen in the video.
2. **Shadow Sandbox** — a Coding-track agent that clones the target repo into a Token
   Factory sandbox, where it writes, runs, and tests against the shadow copy; only a
   verified diff is proposed to the real repo, with the test report attached.
   - Principle 26 (copying) over the agent-writes-code vs don't-break-the-real-thing
     contradiction.
   - Judge leap: the safety mechanism is the story — a coding agent demo that can be
     run live without a live audience flinching.
3. **Nemotron Jury** — writer, critic, and verifier as three instances of the same
   Nemotron family, so the multi-agent demo stays 100% inside the open-infrastructure
   story while still showing real orchestration on Token Factory.
   - Principle 33 (same-model ensemble) over the model-orchestration-impresses vs
     proprietary-model-leaks-in contradiction.
   - Judge leap: "one family, three roles" is a clean answer to both the Tech
     Implementation criterion and the ownership framing at once.
4. **Edge-Cloud Relay** — Physical AI: a Jetson Orin Nano running GROOT/Cosmos perceives
   and acts on-device; Nemotron on Nebius is the planning layer it reports to; the
   mandatory 1-minute hardware clip is the Jetson doing its job.
   - Principle 17 (another dimension) over the PoC-vs-complete-product contradiction —
     adding the edge layer is what makes the loop a product instead of a demo.
   - Judge leap: the track prize is a Jetson Orin Nano per track winner, so the demo
     literally builds toward the hardware it is awarded.
5. **Traceable Researcher** — a Tavily-powered research agent (aiming at the $3,000 Best
   Use of Tavily prize) where every claim carries a confidence score and a visible
   source line, and low-confidence claims are marked in the UI instead of hidden.
   - Principle 23 (feedback) over the fluent-answer-vs-credible-impact contradiction.
   - Judge leap: uncertainty made visible is the non-obvious use — most agent demos hide
     their failures, this one prices them.
