# Idea Database

One directory per problem that has been ideated: `ideas/<problem-slug>/`.

- `set-<n>.md` — one brainstorming set: method (TRIZ, SCAMPER, first-principles,
  cross-domain, inversion), date, and the candidate ideas with one-line rationale each.
- `ranked.md` — the judged shortlist: idea, score per criterion (novelty, feasibility,
  impact, judge-appeal), total, rationale, and the human decision (accepted / rejected /
  park) once reviewed.

Ideas are never deleted; a rejected idea stays with its rejection rationale so a later
trend or constraint change can revive it deliberately.
