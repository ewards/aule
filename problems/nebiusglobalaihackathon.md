## Problem statement

Build the next frontier of AI on open infrastructure: build a working AI system on open, independent infrastructure — NVIDIA open source models served on Nebius through Nebius Token Factory, on high-performance GPU infrastructure — and own the whole thing. All submissions must run on either Nebius Token Factory or Nebius AI Cloud and use at least one NVIDIA open source model. Choose one of four tracks:

- **Coding and Agentic Engineering** — coding agents and developer tools: agents that write, run, and test code in Token Factory Sandboxes.
- **Best Apps and Agents** — any app or agent someone would actually use (productivity tool, copilot, self-running workflow), powered by Nemotron models via Token Factory; optional Nebius Serverless Endpoints/Jobs.
- **Personal AI** — an always-on, private assistant with persistent memory, reusable skills, and access to chosen tools; keep your data under your control; tools like NVIDIA NemoClaw, OpenShell, Hermes Agent, and Nebius Serverless.
- **Physical AI** — embodied and edge agents that sense and act in the real world (robotics, IoT, on-device intelligence), powered by Nemotron, GROOT, Cosmos, and Sonic models; demo must include ≥ 1 minute of the physical hardware/robot operating (or key application modules in action).

## Context

- Online, public; $50,000+ in prizes (cash + hardware/other); deadline Oct 30, 2026 @ 10:00am PDT. Managed by Devpost.
- Submission: working project in a chosen track; project description; working demo URL (not required for Physical AI); ≤ 3-min public YouTube demo video with audio covering use of Nebius Token Factory and NVIDIA models (Physical AI: ≥ 1-min hardware clip); public code repo (GitHub/GitLab/Bitbucket) with visible open-source license (Apache 2.0, MIT, MPL 2.0, etc.) and README with setup instructions highlighting NVIDIA model and Nebius usage; feedback on Nebius/NVIDIA tools; written explanation if the project pre-dated the submission period.
- Judging: Technological Implementation (effective use of Nebius + NVIDIA models in the solution); Design (complete, coherent product experience, not just a PoC); Potential Impact (credible, specific case for a real problem and audience); Quality of the Idea (creative, non-obvious use; genuine understanding of the problem space).
- Prizes: Grand Prize $20,000; 2nd $10,000; 3rd $6,000; one NVIDIA Jetson Orin Nano per track winner (4); Best Use of Tavily $3,000; City Winner Awards $500 × 20 (IRL Builders & Brews event attendees); Most Valuable Feedback $100 × 10 + NVIDIA swag pack.
- Above legal age of majority in country of residence; all countries/territories, excluding standard exceptions.
- Local Builders & Brews onboarding events in various cities (luma.com/builderandbrews).
