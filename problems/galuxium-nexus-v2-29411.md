## Problem statement

Build profitable SaaS platforms that real users will pay for — launch the next generation of AI, creator, and automation tools. Galuxium Nexus V2 is a global hackathon where builders create real SaaS products designed to generate revenue: shift from throwaway prototypes to live, monetizable digital infrastructure. Mandate: build software the world will actually pay for — fully functional, revenue-generating SaaS platforms (autonomous AI systems, creator tools, workflow automation). "Stop building prototypes. Build a company."

## Context

- Online, public; $2,600 in prize value (paid as Backboard.io credits, explicitly no physical cash); deadline Oct 31, 2026 @ 5:00pm IST.
- Eligibility: Devpost tag says students only / 18+ / companies excluded, but the organizer text says to ignore that tag and states the event is open to professional engineers, founders, and builders of all ages (unrestricted).
- Submission (all required for judging): production-ready live deployment on a public cloud/edge (Vercel, AWS, GCP, Fly.io) — link must be live and stable; public GitHub repo with professional README (architecture, tech stack, DB schemas, local replication instructions, authentic commit history); working end-to-end MVP with real state management; executive briefing (market friction, architecture, target cohort); monetization blueprint (usage-based API billing, tiered subscriptions, or transactional fees); 2–5 min product demo video (no video = ineligible for grading).
- Judging: Technical Architecture & Scalability 20%; Enterprise Governance & Compliance 20% (security, privacy, responsible AI); Product Innovation & Market Fit 20%; Monetization & Fiscal Design 15%; UI/UX & Visual Refinement 15%; Keynote Pitch & Demo Completeness 10%.
- Prizes: 1st "Nexus Sovereign Grand Champion" $1,000 (Backboard.io credits + feature + certificate; requires active Backboard Starter $5/mo account); 2nd $500 (credits); 3rd $100 (credits); Galuxium Executive Seed Fund up to $1,000 — discretionary incubation grant at board discretion requiring enterprise-grade architecture, production AI orchestration (agentic workflows/RAG, not API wrappers), live integrated payment infrastructure with webhooks and metering, institutional UI/UX, and data-governance readiness; locked if no submission qualifies.
- Host: Galuxium; sponsors YouCam API (Perfect Corp); coding partner Backboard.
