## Problem statement

WebMCP is an emerging open standard that lets websites expose structured tools agents can use directly. Instead of leaving agents to guess their way through a UI, you define exactly how they can use your app, so they complete tasks faster, more accurately, and more reliably. The challenge: build a WebMCP-powered web app that becomes meaningfully better when people and their agents can use it together — imagining the future of the open web where humans and agents interact, collaborate, and create together.

## Context

- Online, public; $35,000 total (top 10 submissions each receive $3,000 cash, a Codex Micro, ChatGPT Pro for one year, merch, plus supporter prizes); deadline Sep 3, 2026 @ 1:00pm PDT.
- Build a new WebMCP-enabled app or add WebMCP support to an existing one; the repo must register tools via `document.modelContext.registerTool(...)` (name, description, inputSchema, execute).
- Host on ChatGPT Sites, Cloudflare, Vercel, Render, Netlify, Shopify, or any deployment platform; authentication allowed (credentials on the submission form). Test in ChatGPT's in-app browser (WebMCP out of the box) or Google Chrome with chrome://flags/#enable-webmcp-testing.
- Submission: working live URL, text description (why the use case fits WebMCP, how it improves UX, what people and agents can do together that was hard/impossible before, how WebMCP was implemented), < 3-min public YouTube demo video with audio, public code repository (GitHub/GitLab/Bitbucket) with a visible open-source license and all code/assets/instructions.
- Judging: WebMCP Leverage (thorough, skillful, working non-trivial implementation); Execution (working project with a complete, coherent product experience); Potential Impact (credible, specific case for a real problem and audience, addressed by what's demonstrated); Creativity & Ambition (novel concept, different from existing concepts).
- Sponsors: OpenAI, Cloudflare, Vercel, Shopify, Google Chrome, Render, Netlify.
