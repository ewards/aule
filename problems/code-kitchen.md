## Problem statement

Code Kitchen S01 — "India's first coding reality show": a national coding reality series for India's elite working developers, an 8-episode AIM Originals series streaming on YouTube, presented by Google Cloud. Entry runs through a month-long, build-at-your-own-pace audition that narrows thousands of professionals down to 20 (10 teams of 2 "digital architects") who compete in filmed studio battles for a ₹10 Lakh prize pool. Audition flow: submit a concept note → get selected for the audition with pre-funded Google Cloud build credits → build and submit code plus a video screentest → clear final screening and be paired into a team.
