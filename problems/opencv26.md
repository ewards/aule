## Problem statement

Build vision systems that see, reason, and act with OpenCV 5 and Amazon Web Services (AWS). Turn an ambitious idea into a working vision application, demonstrate measurable value, and share it with the global OpenCV community. The competition emphasizes Physical AI and Generative AI systems in which visual understanding drives useful decisions, actions, predictions, or interactions. Every entry must use OpenCV 5 for substantive image or video analysis and run a meaningful component on AWS. Two optional featured paths offer separate $1,000 awards: **Best Use of COOL** (Cloud-Optimized OpenCV Library, must execute the core workload on AWS Graviton/Arm with reproducible measurements vs a baseline) and **Agentic Vision** (an agent uses OpenCV 5 in a multi-step perception→decision→action loop where visual evidence changes what the system does next). Any programming language or hardware allowed.

## Context

- Online, public; $12,000 in cash; final projects due Oct 26, 2026 @ 11:45pm PDT (11:59pm Pacific per page); judging Oct 27 – Nov 9; winners announced Nov 10 (OpenCV Live! webinar).
- Timeline: proposals accepted from Aug 13 (launch Aug 12, 2026); 50 teams selected for $150 AWS cloud compute grants; two-month build phase Aug 26 – Oct 26 (grant teams owe one 30-min Zoom check-in Sep 21 – Oct 2); $100 AWS Free Tier credits for new customers.
- Suggested areas: active perception for autonomous inspection with agentic orchestration/MCP; physics-informed video prediction; multi-agent visual SLAM; real-time spatial digital twins; COOL-based serverless/container/hybrid pipelines; developer agents integrating COOL with Codex/Claude Code/Kiro/MCP; healthcare, safety, accessibility, agriculture, environment, smart cities, education, retail, sports.
- Final submission: technical report (problem, users, architecture, OpenCV 5 implementation, AWS deployment, evaluation, limitations, responsible use); code repo (public or judge-accessible; need not be open source); pinned dependencies + build/deploy/test instructions; architecture diagram; working web endpoint or live screen-share demo; ≤ 5-min video (team, app working, architecture, results); evaluation evidence including failure cases/limitations.
- Judging: Technical execution 30% (correctness/depth of OpenCV 5); Innovation 20%; Real-world impact 20%; User experience 10%; Documentation & presentation 10%; Cloud delivery, reproducibility & responsible operation 10%.
- Prizes: 1st $5,000; 2nd $3,000; 3rd $2,000; Best Use of COOL $1,000; Agentic Vision $1,000.
- Eligibility: above legal age of majority; all countries/territories excluding standard exceptions. Sponsor: AWS; administrator: OpenCV Foundation.
