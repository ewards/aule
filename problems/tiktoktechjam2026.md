## Problem statement

Build with joy, code for change. 72 hours, 5 distinct challenges, $15,000 grand prize: fly solo or form a team of up to 5 members to build solutions for real-world problems across TikTok's challenge tracks (track-specific problem statements released via the TikTok TechJam 2026 Information Document, bit.ly/TikTokTechJam2026Info). Includes virtual technical workshops with TikTok engineers and connections to hiring teams.

## Context

- Online, public; $34,500 in cash prizes; deadline Sep 1, 2026 @ 12:00pm SGT (72-hour window Aug 29 12:00pm – Sep 1 12:00pm SGT).
- Eligibility: ages 18+ only, college students only, companies/professional organizations excluded, only specific countries/territories included.
- Registration required via BOTH the registration form (bit.ly/TikTokTechJam2026Registration) and Devpost.
- Submission: written description detailing solution and tech stack, public code repository (well-structured code, comprehensive README), public 3-minute YouTube demo video showcasing the working solution end-to-end; track-specific deliverables per the Information Document.
- Judging: Technical Execution (engineering fundamentals, well-structured code, thoughtful architecture, reliable demo); Innovation & Problem Insight (originality, sharpness of problem understanding); Impact & Relevance (value to real users, meaningful reach, beyond the hackathon prompt); Feasibility & Practicality (buildable beyond prototype, sustainable architecture); Presentation & Communication (clarity; final event only: coherent pitch + depth in Q&A).
- Prizes: 1st $15,000; 2nd $8,000; 3rd $5,000; 4th $3,000; 5th $3,000; People's Choice $500.
- Key dates: finalists announced Sep 8; Grand Final Sep 11, 9:00am–6:00pm @ TikTok Singapore; winners announced Sep 15.
- Host: TikTok (Early Careers APAC).
