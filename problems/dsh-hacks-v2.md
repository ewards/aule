## Problem statement

Building meaningful technical products in AI and healthcare that solve real-world problems. Theme: AI x Healthcare. Global student competition (hosted collaboratively by DeltaForge Hacks, NXT Horizon, and STEMise): identify a real-world healthcare problem and design/develop a meaningful technical solution — diagnostic tools tackling global disease burdens, patient-care platforms improving access and outcomes, or AI-powered systems reimagining how we detect, treat, and manage illness. Solutions can be an app, website, simulation, system, or algorithm; AI use is encouraged to lower the technical barrier for beginners.

## Context

- Online, public; 1 non-cash prize (winner pool: $100 cash + $100 AoPS gift card); event window Jun 24 – Nov 8, 2026; deadline Nov 7, 2026 @ 11:45pm PST (Nov 8, 2:45am EST).
- Eligibility: ages 13+ only; students only; companies/professional organizations excluded; all countries/territories excluding standard exceptions. Solo or teams.
- Submission: project with user interaction (website, app, or other coding prototype; hardware allowed if a coding component is present); demo video (purpose, features, user interaction); one-page PDF project description (purpose + key features); GitHub repository or code PDF showing all developed code.
- Judging: Idea (addresses problem statement and theme, innovative, potential public impact); Implementation (works, goals achieved, technical challenge/impressiveness); Design (UX thought, interface quality); Presentation (clearly defines and addresses the problem statement).
- Hosts: DeltaForge Hacks, NXT Horizon, STEMise. Sponsors: AoPS, HowtoHackathon, DevSwarm. Judges include AWS Senior Solutions Architect, MuleSoft/Edge AI ambassadors, Texas HHSC Principal Engineer, U.S. Bank SWE.
