## Problem statement

Build and deploy a next-generation, autonomous AI agent leveraging Gemini 3.5 Flash that operates beyond standard chat loops: it can run asynchronously in the background, handle the heavy lifting of complex workflows, or dynamically manipulate data pipelines and representations. Enter in one of three tracks: Taskmaster (a complete workflow agent that takes action on messy multi-step chores), Collaborative Partner (an agent that leads, asks clarifying questions, guides step-by-step, and captures feedback), or Fortified Enterprise Fleet (a scalable network of institutional agents with an agent registry, runtime + memory bank, identity/gateway/Model Armor security, and observability telemetry).

## Context

- Online, public; $180,000 in prizes; deadline Aug 31, 2026 @ 5:00pm PDT.
- Every project in every track must use: Gemini 3.5 or newer via Gemini API or Vertex AI; at least one Google Agent Framework (Google ADK, GenAI SDK, Antigravity SDK, or GenKit); at least one Google Cloud infrastructure service (e.g. Cloud Run, Cloud SQL, Firestore, GKE, Pub/Sub).
- Must demonstrate it was built and deployed on Google Cloud (proof in demo video/repo); the app does not need to be live at judging time.
- Submission: hosted URL (highly encouraged), text description (features, technologies, data sources, learnings), public code repo URL, spin-up instructions in README.md, architecture diagram, ~4-min demo video showing the app in action with visible Google Cloud backend proof.
- Judging: Innovation & Operational Utility 40% (real-world friction removed autonomously); Architectural Discipline & Tech Stack 30% (decoupling, state/memory, credentials, failure handling); Demo & Production Readiness 30% (live unedited demo, clean architecture diagram, reproducible setup, proof it runs on Google Cloud).
- $150 Google Cloud credits available; bonus points for public build content/social post (#AllThingsAgenticHackathon) or integrating Gemma, Veo, or Lyria.
- Host: Google; managed by Devpost.
