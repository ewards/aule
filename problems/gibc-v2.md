## Problem statement

A global hackathon for foundational LLMs, applied AI, and open invention. Getting code to run has never been easier; getting a system to actually work at scale under real constraints is still hard — that gap is what this hackathon is about. Fully online, student-led international hackathon (10-week build, Jul 11 – Sep 21, 2026), solo or teams up to 6, one project per team into one of three tracks:

- **Track 01: TECH (Foundational LLM Development)** — build and train a language model from scratch capped at 50 million total trainable parameters (incl. embeddings and output head); design the architecture, curate the data, write the training loop; scored on defined benchmarks.
- **Track 02: Applied (Medical Technology & Finance)** — a data-driven system on real, empirical datasets (public or de-identified) solving a healthcare or finance problem: predictive models, diagnostic pipelines, automated financial systems; no deployment on real patients or real money.
- **Track 03: Open (General Technical Invention)** — a functional prototype showing technical novelty and cross-disciplinary engineering: software, hardware, interactive media, generative systems, or combinations.
