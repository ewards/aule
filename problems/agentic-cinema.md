## Problem statement

Build a functional agent — powered by Gemini and Google Cloud Agent Builder — that integrates a Partner Entity's product or MCP (IBM, Grafana Labs, Parallel, ClickHouse, or Replit) to power a real media & entertainment workflow.

## Context

- Online, public; $75,000 in cash; deadline Sep 9, 2026 @ 2:00pm PDT.
- Build the agentic workflow on Google Cloud using the Gemini Enterprise Agent Platform; connect to the chosen partner tool via enterprise pipelines, API frameworks, or managed protocol adapters.
- Compete within one of five partner tracks; you are judged exclusively against other builders in your chosen partner track (identical prize buckets per track: $7,500 / $4,500 / $3,000).
- Submission: URL to the hosted project; 3-minute demo video showing the agent functioning as built (public on YouTube/Vimeo, English or subtitled); public open-source repository with a detectable license that must contain all source code, assets, and run instructions and demonstrate actual runtime use of Google Cloud and the partner service (imported and called in code, not just named in the README); selected partner track.
- Judging: per partner track by a panel of partner and Google judges; emphasis on a deterministic, multi-step agent that solves enterprise friction in a media & entertainment workflow.
- Above legal age of majority; specific countries/territories excluded (see page rules).
