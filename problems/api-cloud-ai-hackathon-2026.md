## Problem statement

Join the nation's largest challenge-driven API + Cloud + AI hackathon @ API World 2026. Challenge-driven: each sponsor offers its own track with a concrete API to build on — build a working product where the sponsor's API is functionally central. Tracks:

- **Overall Winner** ($12,500) — best project overall.
- **Perfect Corp** — build an immersive web/mobile consumer experience using Perfect Corp's AI/AR suite (virtual try-on, AI skin analysis, recommendations, text-to-image, fashion visualization); must integrate ≥ 1 Perfect Corp API with clear consumer/retail value.
- **Foxit Software: "Your Agent Shouldn't Sign That"** — build an agent that starts from a plain prompt and ends with a signed document, using the open-source Foxit PDF Services MCP server (40 tools) and a deliberate human-in-the-loop eSign handoff via the Foxit eSign API with its own credentials.
- **Doctavian** — bring your messiest real-world data problem and build an AI agent that turns it into a document that gets it right, repeatedly, using Doctavian's generation API for real documents.
- **name.com Domain API Challenge** — build a product powered by the name.com API (domain search, availability, registration, DNS) as a core part of the build.
- **Nutrient DWS** — turn messy documents into something useful and trustworthy for regulated work (parsing, extraction, conversion, redaction, signing, archiving with replayable output, audit trails, human-in-the-loop) using Nutrient DWS for at least one core document operation.
- **SerpApi Best AI Use Case** — build an innovative AI application using SerpApi for reliable, structured, real-time web data.
- **Xano: Rebuild a SaaS Tool You Hate** — pick a business application you use today and build a better AI version, using Xano as the backend in a meaningful way.

## Context

- Hybrid: in-person + awards at Santa Clara Convention Center, Santa Clara CA, Sep 2–3, 2026 (co-located with API World 2026); online Aug 17 – Sep 3, 2026; $39,500 in cash; deadline Sep 3, 2026 @ 10:00am PDT.
- Register on Devpost; kickoff talk and full step-by-step instructions published by DevNetwork.
- Submission (per tracks): project name + one-line pitch; public repo (or shared link) with setup instructions; 1–4 min demo video end-to-end; project page with write-up and screenshots; explanation of where the sponsor API does the real work; build story for Xano track.
- Judging: sponsor-specific criteria per track (e.g. name.com: API integration depth, creativity/originality, technical execution, real-world viability, presentation/demo); Overall Winner judged by a DevNetwork panel (DevNetwork founder + engineers from Nutrient, Perfect Corp, Maven Mule, name.com, SerpApi, Snowflake, eBay, Google).
- Prizes per track: Overall $12,500 (+ Echoes, 2027 all-access passes, 60k-subscriber announcement); Perfect Corp $2,500 (2); Foxit $1,000 (2); Doctavian $1,000 + subscriptions (2); name.com $2,000 (2); Nutrient $1,500 + DWS credits (2); SerpApi $3,000 + credits (2); Xano $2,500 + credits (2).
- Age 18+; participants from any country allowed.
