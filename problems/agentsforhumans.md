## Problem statement

Every day, people lose hours to small, repetitive tasks like paying bills, scheduling meetings, or filling out the same paperwork again. On their own they're minor, but together they drain real time and attention. Build an AI agent with the Strands Agents SDK that handles routine and repetitive tasks in the background — instead of another app people open and manage, the agent runs autonomously and only surfaces when there's a real decision to make.

## Context

- Online, public; $40,000 in cash; deadline Sep 14, 2026 @ 5:00pm PDT.
- Three tracks: Everyday Agents (daily life, home, money, health, errands, family), Professional Agents (make someone dramatically better at the work they already do), Good Neighbor Agents (groups of people: neighborhoods, nonprofits, food banks, schools, libraries, small local orgs).
- Must be built with the open-source Strands Agents SDK; deploying with Amazon Bedrock AgentCore strengthens the Technical Implementation score but is not required. $50 in AWS credits available via the Resources tab.
- Submission: text description (what it does, who it's for, how it works), PUBLIC code repo URL with MIT or Apache license visible in the About section, all source/assets/setup instructions, README, architecture diagram, demo video (max 5 min) demonstrating the working project and covering (1) the problem, (2) who it's for, (3) why it matters; AWS Builder ID; optional live demo link (scores higher). Bonus points for a build-story post on builder.aws.com using "Agents for Humans" in the title.
- Judging: Technological Implementation (thorough, skillful, working non-trivial use of Strands Agents; live demo/AgentCore strengthens); Design (complete, coherent product experience, not just a PoC); Potential Impact (credible, specific case for a real problem and audience, addressed by what's demonstrated); Creativity & Originality (non-obvious use of Strands Agents, genuine understanding of the problem space); Presentation (clear end-to-end demo, easy to follow).
