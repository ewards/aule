## Problem statement

Build across Amazon Devices and shape what's next. For the first time, Fire TV, Alexa+, Ring, and Bee are all part of one global hackathon — build for one product or use several to connect the living room, the front door, and the cloud. Pick a primary track and ship a working demo; each project can win one track prize and one mini-challenge prize:

- **Fire TV** — launch a demo-ready app on Fire OS or Vega OS (React Native, web, or Android Kotlin/Java). Priority: AI-enhanced viewing, sports, fitness, family entertainment, multi-modal UX, computer vision.
- **Alexa+** — build a self-hosted MCP server (spec 2025-11-25 or later, Streamable HTTP) or an Agent Skill; new to MCP? Build a simulated Alexa+ experience in a web app with your preferred agentic tool.
- **Bee (Wearable AI)** — connect to real data recorded/processed through a Bee device or Apple Watch running Bee software, using Bee's CLI, MCP, or Agent Skills; the demo must show the project using that data to do something useful. Priority: education, developer experience, personal productivity.
- **Ring** — build a new app or extend an existing one with Ring APIs, SDKs, simulators, or devices (physical device not required). Priority: access control, business systems, IoT home automation, accessibility, caretaking.

Mini challenges (stack onto your track): **AWS Builder** (use AWS services — Bedrock, AgentCore, Strands SDK, Kiro Crew, SageMaker, etc. — with documented integrations) and **Open Source** (new open-source project with a license, or a contribution/PR to a public repo during the window).

## Context

- Online, public; $138,000 in cash prizes ($190K total value incl. AWS credits); deadline Oct 23, 2026 @ 12:00pm PDT. Managed by Devpost.
- Submission: text description; public GitHub repo with all source/assets/instructions and a visible open-source license (Alexa+/Bee/Ring repos must actually call the track's required tech in code — an import, entry point, or loaded agent/flow/MCP config, not just a README mention; Fire TV exception: any framework if the demo video shows it running on a real Fire TV device or Fire TV/Vega simulator); demo video under 3 min (public YouTube/Vimeo, English); product feedback on every tool/API/SDK used; which track(s) and mini challenge(s); if pre-existing, explanation of what changed during the window; optional feature requests and friction logs (friction logs can earn up to a 10% judging bonus).
- Judging: Tech Implementation (effective use of required APIs/SDKs/device capabilities); Design (complete, coherent product experience; intuitive interaction model for the target device); Potential Impact (credible case for customer needs, realistic audience beyond the hackathon); Quality of the Idea (creative use of the tools; genuine understanding of the ecosystem and end-user needs).
- Prizes: Fire TV 1st $25,000 (+ $15,000 AWS credits, Amazon Developer team meeting, feature), 2nd $15,000 (+ $5,000 credits), 3rd $4,000 (+ $1,000 credits); Alexa+ 1st $25,000 (+ $15,000 credits, meeting), 2nd $15,000, 3rd $4,000; Bee 1st $12,000 (meeting), 2nd $8,000; Ring 1st $12,000 (meeting), 2nd $8,000; AWS Builder mini $5,000 (+ $5,000 credits); Open Source mini $5,000 (+ $5,000 credits).
- Product feedback goes directly to the teams building Fire TV, Alexa+, Ring, and Bee; SDKs, simulators, sample code, documentation, and live office hours provided.
- Eligibility: above legal age of majority in country of residence; all countries/territories excluding standard exceptions.
