## Problem statement

Hack the Change Again. HackSocial is a hackathon aimed at benefiting the greater good and giving back to the community — build anything that solves a real-world problem, makes life easier, or simply brings joy; technical or creative. Examples: a web app for time/health/finances management, a mobile app connecting local communities, an AI chatbot for tutoring or mental health, an educational game, a cybersecurity tool, an ML model for predictions/recommendations, an environmental awareness tool. No idea is too big or small — originality, creativity, and usefulness matter more than perfection. Tracks: Beginner (beginner-level experience), AI/ML (practical AI/ML solutions), Visual Design (functional and visually appealing apps), Lifestyle Hacks (health and day-to-day life).

## Context

- Online, public; $3,979+ in prizes (cash + sponsor awards); deadline Aug 31, 2026 @ 11:45pm EDT.
- Eligibility: ages 13+; high school, college, and post-grad students only; companies/professional organizations excluded; all countries/territories excluding standard exceptions.
- Submission: GitHub repo or code files (source code or working prototype); project description (inspiration, tech stack, what you learned); optional screenshots or UI mockups.
- Judging: Technical Execution; Innovation & Creativity; User Interface and Design.
- Prizes: Formaloo no-code credits $500 × 5 (one per category + top-voted project); Boot.dev yearly subscription (~$399) for the winning project (all participants get 1 free month); free .xyz domain × 100 best projects; Wolfram One access for all participants; Knowledge Owl yearly membership (~$1,080).
- Sponsors: Formaloo, Knowledge Owl, Boot.dev, XYZ Domain Names, Wolfram Alpha.
